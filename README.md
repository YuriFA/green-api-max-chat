# GREEN-API MAX Chat

Прототип веб-чата для мессенджера MAX на базе [GREEN-API](https://green-api.com/max)

## Стек

- Vite + React 19 + TypeScript
- Tailwind CSS v4
- React-hook-form + zod
- Zustand
- Vitest + Testing Library
- Oxlint + Oxfmt

## Запуск

```bash
pnpm install
pnpm dev
```

Откройте <http://localhost:5173>.
